Политика конфиденциальности

Расширение Chrome «VKVideo flipper». Дата обновления: 24 октября 2026 г.

1. Общие сведения

VKVideo flipper — расширение браузера Chrome для горизонтального отражения видео на VK Видео и во встроенных плеерах. Эта политика описывает, какие данные обрабатываются расширением и для каких целей.

2. Какие данные обрабатываются

  • Настройки расширения (локально): состояние ручного отражения и автоанализа, снимок результата анализа, сведения о решении для текущего URL.
  • Кадры видео: при включённом автоанализе расширение снимает кадры со страницы плеера только для локального OCR. Кадры не загружаются на наши серверы.
  • Аналитика: если автоанализ решил, что видео нужно зеркалировать, на PostHog (us.i.posthog.com) может быть отправлен URL страницы и технические параметры решения (секунда кадра, счётчики OCR). Кадры видео и полный текст OCR не отправляются.
  • Анонимный идентификатор: случайный идентификатор устройства хранится локально и используется только для аналитики событий зеркалирования.

3. Где выполняется обработка

Распознавание текста (OCR) выполняется локально на устройстве пользователя через Tesseract.js (Wasm), входящий в пакет расширения. Внешние OCR-сервисы не используются.

4. Доступ к сайтам

Расширение запрашивает доступ к доменам VK Видео (vkvideo.ru, vk.com, vk.ru) и к страницам Яндекса, где может быть встроен плеер VK (yandex.ru, ya.ru), чтобы найти элемент видео, применить отражение и при необходимости выполнить автоанализ. К другим сайтам расширение не обращается, за исключением указанного endpoint аналитики.

5. Передача третьим лицам

Минимальные события аналитики (в том числе URL при успешном автозеркалировании) могут передаваться в PostHog. Мы не продаём персональные данные и не используем их для рекламы.

6. Хранение и удаление

Локальные настройки хранятся в chrome.storage.local и удаляются при удалении расширения. Пользователь может сбросить данные расширения в настройках Chrome.

7. Дети

Расширение не предназначено для сбора данных детей и не ориентировано специально на пользователей младше 13 лет.

8. Изменения политики

Мы можем обновлять эту политику. Актуальная версия публикуется на этой странице с датой обновления.
