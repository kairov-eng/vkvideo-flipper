# VKVideo flipper

Chrome-расширение для горизонтального отражения (flip) видео на VK Видео.

## Зачем

Иногда ролик на `vkvideo.ru` уже зеркально отражён по горизонтали: текст и интерфейс в кадре «перевёрнуты». Расширение отражает картинку ещё раз, чтобы видео стало читаемым. Кнопки плеера, таймлайн и меню не переворачиваются — меняется только само изображение.

## Возможности

- **Ручное отражение** — переключатель в меню сразу включает или выключает flip на странице.
- **Автоанализ** — на `vkvideo.ru/video-…`, `vk.com/video-…` и во встроенном плеере из Яндекса (`video_ext.php`) расширение снимает кадры, прогоняет OCR и само решает, нужно ли зеркалирование.
- **Окно анализа** — миниатюра кадра и технические данные OCR; можно открыть из меню и перетащить за заголовок.
- **Метка на странице** — в правом верхнем углу появляется «Видео зеркалировано».
- **Сброс при смене URL** — отражение и данные анализа сбрасываются для следующего ролика.

## Как установить

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `VKVideo flipper`.
4. Откройте ролик на VK Видео и обновите вкладку.

## Как пользоваться

1. Для ручного flip включите **Отражение**.
2. Для автоопределения включите **Автоанализ** на странице `vkvideo.ru/video-…`.
3. Нажмите **Показать окно анализа**, чтобы увидеть миниатюру и OCR-статистику.
4. Горячая клавиша отражения: `⌥⇧F` (можно изменить в `chrome://extensions/shortcuts`).

## Приватность

OCR выполняется локально через Tesseract.js внутри расширения. Кадры не отправляются на внешние серверы.
