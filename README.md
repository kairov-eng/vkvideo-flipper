# VKVideo flipper

Chrome-расширение для горизонтального отражения (flip) видео на VK Видео.

Автоанализ по OCR находит зеркальный текст в кадре и включает отражение только когда это нужно.

## Состав репозитория

- `chrome extention/` — исходники расширения (Manifest V3)
- `screenshots/` — материалы для Chrome Web Store
- [privacy-policy.html](./privacy-policy.html) — политика конфиденциальности

## Установка (режим разработчика)

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика»
3. «Загрузить распакованное расширение» → папка `chrome extention`
4. Откройте ролик на VK Видео и обновите вкладку
